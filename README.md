# Task 4 - Responsive Design Tokens & Mobile-First CSS Architecture

## Objective
Create a responsive web interface using modern CSS custom properties, mobile-first breakpoints, CSS Grid, Flexbox, fluid typography, spacing tokens, and responsive components.

## Features
- CSS custom properties for colors, spacing, radii and shadows.
- Mobile-first base styles.
- Breakpoints for 768px, 1024px and 1440px.
- CSS Grid for project cards and page sections.
- Flexbox for navigation and card metadata.
- `clamp()` for fluid headings.
- Responsive navigation with an accessible mobile menu.
- Responsive contact form.
- Keyboard-visible focus styles.
- No intentional horizontal overflow.

## Files
- `index.html` - responsive dashboard demo.
- `css/styles.css` - design tokens, components and breakpoints.
- `js/menu.js` - mobile navigation behaviour.

## Testing
Test at:
- 320px mobile
- 768px tablet
- 1024px desktop
- 1440px wide desktop

Capture screenshots at these viewport widths for the internship proof.
