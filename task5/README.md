# Task 5 - Dynamic JavaScript DOM Logic & RESTful API Client

## Objective
Build a dynamic JavaScript client using async/await and a public REST API.

## Features
- Async/await REST API integration
- Separate `app.js` and `api.js` modules
- Search and category filtering
- Sorting by price, rating and title
- All/Favorites tabs
- `localStorage` favorites
- Dynamic DOM rendering
- Loading and error handling
- Responsive UI and focus styles

## API
Fake Store API: `https://fakestoreapi.com/products`

## Structure
```text
task5/
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── api.js
│   └── app.js
└── README.md
```

## Run
Use a local server because ES modules are used. For example:
`python -m http.server 8000`

Then open `http://localhost:8000`.
